# References

`catalogue.toml` lists every literature source the project relies on. For each
one it records:

- **how far it has been checked:** citation, abstract, or full text. The docs never
  claim more than that.
- **its licence.** Only material whose licence allows it (for example CC BY) is
  stored in this repository. Everything else is cited and linked.

Docs cite entries as `[@id]`. The test suite checks that each catalogue entry is
valid and that every citation resolves.

Reference images of specimens will go in `references/images/`, each with its own
source and licence entry, once collected.
