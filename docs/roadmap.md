# Roadmap

Milestones end with a check-in: results, images, and the next decisions.

| Milestone | Scope | Status |
|---|---|---|
| **M0: Foundation** | Repository layout, ADRs, archetype registry (12 forms, all pending), reference catalogue, science notes draft, CI | done |
| **M1: First procedural models** | 2D grid and exact cavity geometry; 9 preset cavity shapes (volcanic, sedimentary, seam); run config and records; procedural fortification, seam and waterline, verified with negative controls; `agatesim run` CLI; PNG output | done |
| **M2: Web UI v1** | Rendering touch-up; 14 openly licensed specimen photos; FastAPI backend; React app with parameter panel, preset shape menu, live preview, background runs, run browser, slab viewer with growth slider and comparison | done |
| **M3: Schedules and the combined form** | Formation time and schedules (timeline editor in the UI); procedural growth model; combined fortification–waterline (both stage orders); quartz-centre geode; band-statistics module with run comparison ([ADR 0007](adr/0007-formation-history-and-growth-model.md)) | done |
| **M4: Drawing tool and nucleation** | Cavity drawing tool (corners or freehand, angular or smooth); tubes placed by clicking; spherulitic growth from nucleation sites → botryoidal, eye; tube agate; quartz crystals with pointed growth forms that coarsen by geometric selection ([ADR 0008](adr/0008-drawn-cavities-nucleation-and-crystal-growth.md)) | done |
| **M5: Dendrites** | Literature pass (two reviews and a dendrite study read in full or in part); multi-particle DLA inclusions on a world-scale lattice, enclosed by later chalcedony → moss; upward-biased growth → plume ([ADR 0009](adr/0009-branched-inclusions.md)) | done |
| **M6: Optical renderer** | Literature pass (iris spacing; no shadow-agate optics found); thin-slab single-scattering renderer → shadow; micro-banding field and grating renderer → iris; live optical views ([ADR 0010](adr/0010-optical-renderer.md)) | done |
| **M7: Specimen analysis I** | Photo scale with perspective correction; automatic specimen outline; observed fields; form identification validated on synthetic photos (passes reliable, fails uninformative); replica fitted in the specimen's outline; Specimens screen ([ADR 0011](adr/0011-specimen-analysis-first-pass.md)). M7.1: whole bands traced along the photo's band direction ([ADR 0012](adr/0012-band-tracing-along-the-band-direction.md)) | done (first pass, M7.1) |
| **M8: Mechanistic models** | Front feedback (H1): self-organised bands verify fortification and seam at the mechanistic tier ([ADR 0013](adr/0013-mechanistic-front-feedback.md)); supply forcing and band-sequence statistics: bands record the forcing's level, not its character ([ADR 0014](adr/0014-band-sequences-as-records.md)); Liesegang precipitation (H2) on an array backend: closed rings with the Liesegang spacing law, but rounded corners, so H2 fails the fortification corner test ([ADR 0015](adr/0015-mechanistic-liesegang.md)); CuPy backend with a fused CUDA kernel (about 70× the CPU); hindered settling (H4) verifies waterline ([ADR 0016](adr/0016-mechanistic-settling.md)); H1 with explicit diffusion: exact linear stability finds no oscillation in 4,000 parameter sets (earlier stick-slip cycles were discretisation artefacts), so H1's bands rest on the boundary-layer approximation. A surface state (adsorbed impurity) restores a converged 1D oscillation, but its fronts are unstable to ripples at all short wavelengths, so the 2D corner test has no converged answer without a further smoothing mechanism (backlog) ([ADR 0017](adr/0017-h1-without-the-boundary-layer.md)); later: H1 and H4 chained as stages verify the combined form ([ADR 0020](adr/0020-staged-mechanisms.md)) | done |
| **M9: 3D** | Cavities as solids (8 presets, drawn outlines extruded); procedural fortification and waterline, H1, H4 and the H1 + H4 stages evaluated at any point; cuts as ordinary 2D results, judged by the unchanged criteria; random-cut surveys: layers and the combined form pass over 90% of cuts, fortification 24–30% because band corners drift off the wall corner's bisector on oblique cuts, 71–76% once the corner test also looks at each band's own corner ([ADR 0022](adr/0022-corners-at-the-bands-own-corner.md)); apparent band thickness 1.07–1.18× true; 3D screen with a rotatable WebGL2 view opened at the cut ([ADR 0021](adr/0021-three-dimensional-runs.md)) | done |
| **M10: Specimen analysis II** | Discriminants between mechanisms (corners, ring closure, floor-width law), validated on simulations; through photos only ring closure survives ([ADR 0018](adr/0018-mechanism-discriminants.md)); hand-marked band boundaries as ground truth for real photos, scored against chance; a full-resolution boundary detector finds about twice as many marks as chance, near the limit of the current photos ([ADR 0019](adr/0019-hand-marked-ground-truth.md)); waiting for better photos: tracing-independent corners, layer tracing, simulation-based inference with uncertainty, quartz and inclusion detection | paused |
